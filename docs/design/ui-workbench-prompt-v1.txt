Use case: ui-mockup.
Create ONE exceptionally polished, high-fidelity desktop application UI design image for an Electron browser automation and AI Agent platform. The user wants a beautiful, practical product interface. This is the actual in-app browser automation workspace, rendered front-on as a crisp flat screenshot, not a marketing website, diagram, wireframe, device photograph, or tilted mockup.

Canvas: wide landscape, approximately 16:10, high resolution, excellent legible Simplified Chinese typography. One complete application window fills almost the entire frame, with only a slim neutral margin. Precise grid, generous but purposeful spacing, subtle borders, carefully aligned icons, elegant hierarchy, realistic professional software. Design feels refined, quiet, confident, and buildable. Warm off-white workspace, white surfaces, charcoal navigation sidebar, restrained warm amber/copper for primary interactions, muted jade for healthy/running status. Avoid purple gradients, neon, excessive glass, oversized cards, and decorative charts.

Product concept: user and AI operate THE SAME real embedded browser page; account profiles are switchable; tasks extract website information and publish structured output. Make the live webpage the primary visual focus, with a right-hand AI collaboration pane and a compact results panel underneath the browser. Display an active task, not an empty dashboard.

Composition:
1. Left navigation around 13% width, full height, charcoal. Top is a small understated abstract application symbol and Chinese product label "自动化工作台". Workspace switcher "个人空间". Navigation items with fine consistent outline icons: "浏览器" (selected), "自动化", "账号管理", "数据集", "服务接口", "运行记录". A small lower section "最近任务" with "商品信息采集" selected and "内容更新监测" beneath. Bottom has "设置", a circular avatar, and a small status "本地运行". Selected row is slightly lighter graphite with a slim amber accent. Clean, tasteful, no large logos.
2. Main workspace around 62% width. Header breadcrumb "工作空间 / 浏览器", title "商品信息采集", a small green-dot badge "运行中". At right of header place secondary outlined "暂停" and primary amber "接管浏览器". Use restrained Windows-style minimize/maximize/close controls in the overall top bar.
3. Immediately below header, an account environment strip with avatar and "账号 A", muted "独立环境", green-dot "已登录", dropdown chevron, and a compact "切换账号" control. Clear visual separation from the target website.
4. Embedded browser frame: two modest tabs labeled "商品目录" and "商品详情", a plus-tab icon, back/forward/refresh controls and a subtle rounded URL field showing "catalog.example.com/products". The website content is a beautiful understated product catalog mock website, visually distinguishable from application chrome: title "商品目录", a search input "搜索商品", categories "全部商品", "数码配件", "音频设备". Three large airy product cards in one row with premium realistic studio cutout product photography: black over-ear headphones, a compact cream portable speaker, and a pale mechanical keyboard, on pale neutral backgrounds. Labels exactly "无线降噪耳机" / "便携蓝牙音箱" / "机械键盘" and prices exactly "¥899" / "¥299" / "¥499". Muted green "现货" by each. On the headphone product card add an elegant thin amber selection outline and small unobtrusive label "正在提取". It should clearly read as an AI-controlled actual website embedded inside a desktop browser, not a metrics dashboard.
5. Under browser, compact approximately bottom quarter results pane integrated with dividers, not floating. Tabs "采集结果" (selected), "执行日志", "输出配置". Small right-side "18 条数据" and "导出". A precise table with columns "商品名称", "价格", "库存", "状态" and three readable sample rows corresponding to the three products above. Status "已提取", using small jade checkmarks. A low-key bottom footer says "输出格式 JSON" and "自动保存".
6. Right AI pane around 25% width, white background with fine left border. Header small refined agent spark icon, "AI 助手", green-dot status "执行中", subtle overflow control. A short user bubble says "采集商品名称、价格和库存，整理成 JSON。". Below, a calm assistant message "正在使用账号 A 浏览商品目录。". Then a clean vertical execution timeline: "验证登录状态" completed; "打开商品列表" completed; "提取商品信息" active in amber; "生成结构化结果" pending. Include a compact inline progress indicator "18 / 24" for extraction. Below is one small evidence/observation card titled "当前操作" with "读取商品价格与库存". At the bottom, a beautiful multiline message composer with placeholder "描述下一步，或调整当前任务…" and attachment plus icon and an amber send-arrow button. Below or just above composer show a subtle short caption "你可以随时接管浏览器". Do not fill the pane with essays, debugging data, code dumps, or artificial chain-of-thought text.

Typography: professional modern Simplified Chinese sans-serif with balanced weights, excellent rendering and generous line height. English identifiers use complementary understated sans/mono. ALL supplied Chinese labels must be accurate and readable; prioritize a small set of crisp text over clutter. In-app task evidence is demo content. No architecture internals like CDP, IPC, Node, sandbox flags in the user-facing screen.
Constraints: one cohesive screen, full window visible, no extraneous title outside app, no watermark, no comparison boards, no floating explanatory callouts, no multiple mockup thumbnails, no people, no giant robot illustrations. Visual quality suitable for a polished product design presentation.
