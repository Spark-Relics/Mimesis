# 自定义存储目录

先生成 preferences.png（built-in image_gen，提示见 prompt.md），再实现交互。复用现有 Lucide 线性图标和组件，不新增装饰素材。

保持顶部导航、单列设置；显示当前目录与配置来源、数据库/产物/浏览器文件的范围。目标路径支持输入和系统目录选择器；提交前校验绝对路径、目录关系、空目录与写入能力。保存后显示待迁移路径、保留原目录的说明、取消变更和退出应用。加载、保存、取消、失败均由真实结果驱动。环境变量覆盖时显示来源且禁止被界面悄悄覆盖。

迁移在下一次启动、Electron ready 前完成，期间尚未开放网关或浏览器。原目录锁、复制暂存目录、文件校验清单、完成标记与原子启动配置保证失败可重试。此阶段启动迁移采用同步分块文件 I/O，不展示虚假进度；大目录可能延长启动时间。运行中的 SQLite 仍在独立工作线程。

成功后所有工作区、产物与 Electron sessionData 使用同一自定义根目录；启动配置留在固定配置目录以找到数据。原目录不自动删除，跨机器凭据解密不在此操作承诺内。
