## 信息结构

固定 204px 浅色导航，仅保留自动化实例、浏览器环境、运行记录、设置四个真实入口。内容区顶部采用轻量面包屑和系统窗口控制。每页只突出一个主要动作。

实例总览：标题及创建入口 → 已启用/总数、正在执行、最近成功率 → 搜索及状态筛选 → 实例列表 → 单条运行洞察。列表直接展示目标网站、Profile、最近结果和启用状态。实例工作台：实例标识 → 配置与运行摘要 → 任务、源码及浏览器、配置、历史；结果紧邻执行上下文。

智能体现在有依据且可操作的提示：根据当前实例的最近运行，依次提示失败、尚未验证、正在执行或运行情况。显示“规则分析”，说明来源是最近运行记录，不调用模型、不猜测网站状态。不设置装饰性 AI 聊天面板，不宣称自动修复、账号轮换或无人值守能力已实现。

## 实现与验收边界

指标只读取真实 workspace：成功率分母为最近保存的 succeeded/failed Run，取消不计入，无样本展示破折号，并说明样本范围。运行洞察取每个实例的最近 Run，历史失败已被后续成功覆盖时不得继续告警。没有运行记录时只能标注未验证。

搜索按名称和目标网址匹配，可与启用/暂停筛选组合。空结果提供清除筛选，不能显示伪造实例。按钮保留取消、禁用和等待态。英文与中文采用同一信息结构。1080px 最小桌面宽度保持可读，宽屏内容不无限拉伸。

保留浏览器真实 Session 和输入边界。所有 UI 改动完成后执行类型检查、双语检查、业务测试、Electron 回归和截图核对。后续 RPA SDK 按这一视觉与交互约束继续开发。
